# Signal Crucible SVG concept pack

These are concept-stage vectors for the owner-selected Signal Crucible direction. They do not replace the current production mark.

- `mark.svg` — full-detail mark for 48 px and above.
- `mark-small.svg` — compact mark for 16–48 px UI use.
- `favicon.svg` — self-contained rounded-square favicon/app icon.
- `lockup.svg` — horizontal wordmark lockup; uses Geist when available.

System colors: Obsidian `#080B14`, electric blue `#47BFFF`, violet `#9B6BFF`, restrained magenta `#E853FF`, amber calibration `#FFBE55`, and pale signal `#C9F1FF`.
